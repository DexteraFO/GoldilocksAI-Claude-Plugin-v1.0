# Investment_Ready_Recommendation

Claude plugin marketplace containing **investment-ready-research**: public-source investment screening with scored, evidence-backed shortlists and Mermaid diagrams.

## Install

```
/plugin marketplace add dgpl-harshit-p/Investment_Ready_Recommendation
/plugin install investment-ready-research@investment-ready-marketplace
```

Public data only. The relationship path is always a labelled mock. Research support, not investment advice.
