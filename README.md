# GoldilocksAI Claude Plugin

Claude plugin marketplace containing **investment-ready-research**: investment screening with Goldilocks data and public sources with scored, evidence-backed shortlists and Mermaid diagrams.

## Install

**Claude Desktop / claude.ai:** Customize → Plugins → Add → Add marketplace → `DexteraFO/GoldilocksAI-Claude-Plugin-v1.0`, install **Investment Ready Research**, then open its **Connectors** tab and click **Connect** to sign in to Goldilocks.

**Claude Code:**

```
/plugin marketplace add DexteraFO/GoldilocksAI-Claude-Plugin-v1.0
/plugin install investment-ready-research@investment-ready-marketplace
```

then run `/mcp`, choose `goldilocks` and authenticate.

Uses Goldilocks company data (connect your Goldilocks account after installing) plus public sources. The relationship path is always a labelled mock. Research support, not investment advice.
